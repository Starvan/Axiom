# 任务级自动暂停

目标：用户按主屏 HDR / 本地周时段限制整个任务，列表即时显示自动暂停原因；暂停时停止内部检测，手动暂停保持。

- 后端：schema4 原地持久化、独立事件驱动外层观察、Engine 取消/释放与恢复新基线、HDR 普通检测、状态推送。
- UI：独立自动暂停配置、手动/自动状态与筛选；旧动作执行时段保持含义。
- 取消画面检测内部 HDR 禁止；HDR 是否暂停由任务配置决定。
- 验证仅限本轮模型/存储/订阅/状态流/编辑状态与实际新增 UI；不重复亮度或全 UI 测试。
