# UI 架构：围绕自动化任务

状态：2026-10-18。当前使用通用任务编辑、分类检测/动作选择弹窗、当前托盘多选面板、进程组、Steam 启动同步和任务栏托盘管理工具、融合标题栏、可编辑快捷键与系统/浅色/深色主题。画面检测与夜间暂停模板沿用通用编辑；当前验证范围以交接页为准。

## 信息架构

```text
Axiom
├─ 自动化（默认首页）
│  ├─ 我的规则：名称 / 条件 → 动作 / 已启用或已暂停
│  ├─ 新建自动化 → 何时执行 → 执行什么 → 结束与冲突 → 保存
│  └─ 编辑自动化 → 保存 / 取消 / 删除
├─ 组：组类型入口 → 进程组的创建 / 编辑 / 删除 → 批量输入弹窗或程序文件选择
├─ 工具箱：实用工具入口 → 对象与模式设置 → 启用 / 停用 / 立即操作
├─ 活动记录：按日期分组 / 检测、执行、异常及配置记录 / 较新与更早分页 / 清除七天前记录
└─ 设置：外观主题 / 全局快捷键 / 关闭窗口的行为 / 登录启动开关与位置更新 / 停止后台并退出
```

不再设总览大屏、能力展板、规划中卡片、开发验收说明。首页最重要的是用户已保存的规则和“新建自动化”；后台状态降为辅助信息，列表底部只保留活动记录入口，不重复铺开后台状态和原因。活动记录只展示真实保存的事件，不根据全局状态为每条规则编造执行记录。

## 核心交互

1. 列表使用紧凑分隔行：名称和状态为一级，检测 → 动作为二级，编辑/启用/暂停在行尾。参数、运行时段与退出策略通过详情按钮按需查看，自动暂停原因和状态未确认仍直接显示。编辑与暂停位于对应规则，不显示数据库版本、能力 ID 或内部状态码。
2. 新建/编辑进入独立页面：名称 → 检测什么（类型、参数）→ 执行什么（类型、参数）→ 运行方式。检测和动作是独立类别，即使当前各只有一种，也保留类型选择。目录、分类、字段、资源选项与行为说明由后台注册提供；UI 不按能力 ID 写专用分支。新任务不替用户默认选中 HDR。只提供已接通且兼容的组合，不陈列空能力。
   检测、动作及组合叶子状态类型使用共用应用内选择窗口：左侧为声明类别及“全部”，右侧单选列表，支持名称/说明/类别搜索，底部显示所选类型说明与行为。主表单展示当前类型和“选择/更改”按钮；弹窗只有“选用”才更新编辑器，取消保留原类型及参数，确认相同类型也保留参数。筛选隐藏当前候选或空结果时不自动选另一项，禁用“选用”；兼容性仍由原声明和编辑状态校验。类别、结果及说明独立滚动，弹窗关闭后再回填需核对编辑会话、树代际与目录快照。检测方式、组合方式及参数的小选项仍使用原控件。
3. 保存等待后台确认，成功才回到列表并提示“已保存”。正在请求时禁用重复提交；失败保留输入。版本冲突允许显式重新读取已保存版本，先确认放弃输入；不自动覆盖新版。
4. 取消、切页、关闭窗口时，存在未保存更改先确认。刷新不能抹掉编辑内容或悄悄升级待提交版本。目标显示器暂不可用时保留原选择，不自动换到另一台。
5. 启用是允许检测，不表示正在执行。执行与退出语义、编辑警告由动作声明提供。HDR 适配器须明确运行中暂停/删除/修改会让出本轮控制，保留物理状态，本次退出不再恢复；不能把这条行为推广到所有动作。
6. 关闭窗口只退出 UI；设置内显式停止后台需确认。宿主拒绝停止时说明先正常退出游戏并等待恢复，不强杀后台绕过。
7. 登录启动设置由宿主读写当前用户最高权限的登录计划任务，只有布尔开关，UI 不发送可执行路径。启用后只启动管理员后台，不保存密码；“已登记”不等于已运行。读回未确认时禁用开关并明确状态未知，保存失败显示原因。登记指向其他文件夹时提供“更新启动位置”；提醒 Windows 可延迟启动、删除程序前关闭登记。旧 HKCU Run 启用项由管理员 Host 迁移，关闭状态不新增登记。关闭登录启动不影响当前运行中的任务。
8. 全局快捷键置于设置页顶部，支持新增、编辑、启停、删除；功能选择来自已接通功能目录，当前只有显示 / 关闭 Axiom 窗口，同一组合切换开关，关闭后任务栏按钮消失、后台继续。编辑用功能选择、修饰键和按键；保存等待真实注册和持久化确认。冲突保留输入和旧组合，回复未确认时禁用重复保存并提示取消后刷新。已生效、已停用、未生效及原因分别显示；关闭 UI 后继续监听，停止后台后释放。快捷键不补发旧按键。
9. 外观位于设置页最上方，提供跟随系统 / 浅色 / 深色；首次默认跟随系统。选中后先保存再即时应用，失败保留原选择并说明原因。只更新颜色，不重建编辑表单、不重启后台。主题是 UI 本地偏好，文件 `%USERPROFILE%\.axiom\ui-theme.txt` 以临时文件替换保存；规则、快捷键和登录启动的宿主写入边界不变。
10. 活动记录按日期分组，最新在前，每页按当前窗口可视空间读取合适数量，通过“较新记录 / 更早记录”访问全部保留历史；不一次加载全库。每行突出发生的事，随后显示相关任务/程序（有则显示）、单行原因摘要、绝对时间与类别；普通详情可悬停或点击信息按钮查看，异常原因完整直显，以简洁图标辅助区分完成/提醒/异常。分页返回页首，窗口尺寸变化时回到最新页并重新估算容量；不自动轮询或把刷新记为活动。
11. “清除 7 天前的记录”一键执行，无二次确认；后台以执行时刻 UTC 减七天为界，仅删除严格早于界限的记录，保留边界及之后的活动。事务操作确认后显示删除数量并重新读取最新页；失败/回复丢失不得假报成功，旧内容保留并说明未确认。日志读取/写入异常独立提示，不把日志正常等同于自动化执行正常。
12. 检测字段可声明 `ProcessSelection`：保留所有已保存进程，提供逐项移除、从组勾选/全选/取消组内选择、“批量输入名单…”弹窗及批量选择 exe。多行输入只存在于应用内 ContentDialog，先验证全部名称及数量，确认才加入；取消不改变已有名单，不在表单常驻大输入框。自动化列表只显示检测类型，具体进程名单在编辑页查看，不重复展示“检测的程序：xxx”。名字按大小写不敏感去重，任务和每组上限 128；选入规则后名单独立保存，修改/删除组不改运行中的任务。HDR 与插件适配器各自仍限制最多 128 个不同目标，不能通过增加组绕过。
13. 进程组通过同用户 Host 管道保存到 SQLite，命名、版本冲突、成功/失败及未保存退出保护与任务一致。最多 32 组、合计 512 个程序，另有 IPC 内容大小限制；空组允许暂存。UI 不直接访问组数据库或注册表。
14. “组”首页按组类型展示入口，当前仅有真实可用的进程组；“工具箱”按真实可用工具展示入口，固定场景不要求用户手工拼接检测与动作。统一图标、标题、说明和进入按钮，逐个新增实际工具，不为预留扩展显示空能力。进程组列表在“管理进程组”内，不和类型首页混排。“本机上的Steam游戏”由工具维护，卡片提供“工具设置”而非手工编辑/删除；关闭工具保留组。
15. Steam 卡片提供持久化“每次启动自动更新”开关、工具设置和立即检查更新。默认关闭，首次开启立即同步；开启后每次 Host 启动扫描，不依赖 UI，窗口重开不扫描。仅通过 Steam 元数据更新固定“本机上的Steam游戏”，不再选择导入目的组；完整新名单替换旧名单，扫描失败或库不可用保留原组，组变化不暗改已有规则。工具设置 ContentDialog 显示上次结果、时间、警告、当前名单和长期排除项，搜索/虚拟列表只在弹窗，主工具箱不铺结果。勾选表示排除，支持批量勾选/取消和“批量添加排除项…”；未检测到的排除名仍保留。批量输入每行一个 exe 文件名，验证全部后加入草稿，顺序关闭/重开对话框，取消不修改保存状态；保存以打开时版本校验。安装清单没有 exe，另用 appinfo Windows 启动配置核对具体文件；无法识别时说明原因，不猜 exe，启动器可能不同于真实游戏进程。超过组容量时明确提示调整排除，不能截断假报成功。关闭开关停止自动导出；关闭时手动检查仅更新工具结果。主窗关闭时若有弹窗，先关闭弹窗，再遵守页面未保存保护。
16. 检测目录中的“Axiom 启动时”使用普通 Choice 字段“启动次数”：默认每次启动时，可选本次开机首次启动时；支持启动/关闭程序及关闭窗口，动作字段保留延迟等各自声明的选项。启动指后台启动并准备好执行动作，窗口重开不触发；新建/编辑/启用从下一次后台启动生效。首次是本次开机第一次后台启动，错过首次、失败或取消不补执行；文案与活动明确这些区别，不把已启用写成已执行。
17. “关闭窗口”是窗口类别的独立动作，等待窗口与动作延迟分别解释；每次为每个目标关闭一个主窗口、之后手动打开不干预。编辑提示说明模拟点击 ×，目标软件决定留在托盘还是退出；不把该动作写成强制结束进程，也不承诺任意 GUI 软件都可留在后台。
18. “关闭窗口”“关闭程序”的目标声明 `ExecutableSelection`，复用紧凑名单、逐项移除、“批量输入名单…”应用内弹窗和程序文件多选。每行一个本机完整 exe 路径，大小写不敏感去重，最多 32 个；弹窗一次验证全部，错误保留弹窗与输入，取消不改名单。旧单路径原样读回，不强制迁移或改规则。动作按完整路径匹配，不能直接使用只有文件名的进程组；相似可多对象场景优先多选。文件/目录选择使用已有 Windows App SDK 1.8 的 `Microsoft.Windows.Storage.Pickers`、关联 AppWindow.Id，兼容管理员界面；没有能力 ID 专用分支。
19. “托盘 / 隐藏托盘图标”声明 `TraySelection`，提供“从当前托盘选择…”应用内面板、搜索、刷新、结果全选/取消及逐项勾选；仍可手动批量输入或多选 exe。面板读取当前可识别图标（含折叠区），同一实际 exe 合并并显示图标数和完整路径；不列历史/已移除图标，不能识别不冒充可操作。打开/主动刷新才读取并显示时间，无周期轮询；刷新保留勾选草稿，取消不提交，确认存完整路径，不保存瞬态图标编号；旧名单中暂时没图标的目标保留，仍限制 32 个。参数提供等待图标与延迟执行；一次触发处理当前可识别图标，保留后台进程，软件/资源管理器重建后可能再出现，暂停不恢复，可重新打开或重启目标软件恢复。提醒托盘菜单/气泡通知可能不可用及版本识别限制；结果未确认不写成功，不提供无效恢复按钮；持续管理从工具箱独立启用，不改变此规则动作。

应用文案当前只写中文，未建立其他语言翻译表。发布包移除其他语言的独立 MUI 资源，只保留 zh-CN 和 WinUI 的 en-us 回退；共享框架 PRI 不重新裁剪。后续有真实需求再接入翻译机制，不提前维护多套文案。

20. 键盘检测/动作声明通用 `HotkeyList` 字段，主表单仅显示前三组合摘要及编辑按钮；应用内弹窗选择修饰键/按键并添加、移除，动作支持上移、重复组合，检测去重。批量输入折叠在弹窗内，最多 16 个组合，一次验证全部，错误保留输入，确认才提交、取消不改变原值。检测至少含 Ctrl 或 Alt、F12 系统保留；动作可单键，按序向执行时前台发送。目录提示解释占用/按住不重复、忙时不重放、延迟与暂停取消、输入已发送不代表目标功能成功，以及不能发送 Axiom 当前监听组合。没有键盘能力 ID 专用分支。

工具箱的“任务栏托盘管理”用独立设置窗口配置完整程序路径名单，复用当前托盘多选与批量输入。用户选择“仅Axiom启动时隐藏”或“持续隐藏”，并设置等待图标出现的1–120整数秒；新配置默认30秒，已有配置保留原值。已有图标立即处理，未出现时逐目标并行等待系统通知，超时说明未找到；等待不是固定延迟。保存、启用和立即隐藏均等待后台确认；停用保留名单并停止后续观察/执行。持续模式按系统事件核对目标，无轮询；图标重建仍受系统身份识别限制。说明关闭不自动恢复图标、可能影响托盘菜单及气泡通知。内部任务不出现在普通规则列表，工具关闭或修改不会暗改已有用户规则。

工具箱“快捷键 + 滚轮调亮度”提供启停、Ctrl/Alt/Shift/Win与可选主键的多键组合、主屏/全部支持硬件屏幕、每格1–20百分点、平滑50–1000毫秒及请求上限1–60次/秒。默认Ctrl+Alt+滚轮、2百分点/150毫秒/18次每秒，首次默认关闭；实际频率受设备限制，不称面板帧率。连续滚动由后台合并，未匹配组合正常滚动，UI退出仍可用。

卡片分别显示监听、调整、手动接管和上次结果，读取/保存/执行不混称成功；设置窗等待后台版本确认，失败保留草稿，结果未知禁止重复保存，可显式确认放弃草稿后重读。手动接管保留当下亮度，关闭工具停止后续监听/写入但不自动恢复旧值；“恢复自动亮度”在工具关闭后仍可使用，只有后台确认才更新状态，具体交接见[手动接管](../architecture/manual-override.md)。无定时刷新或按格动作队列。

## 状态与文案

“显示 / 主屏画面大面积明亮”使用通用参数字段：明亮面积进入65%/退出45%、稳定默认3秒，支持0–60秒、最多两位小数（如0.2、0.5）；0秒立即响应第一份有效样本。进入和退出共用该稳定时间，使用最近期限，不增加轮询或采集频率。“检测时段”折叠项可同时填写HH:mm，留空全天、跨午夜；HDR是否暂停由任务级自动暂停显式配置。模板仍生成暂停草稿，用户审阅后启用；画面不保存，亮度目标、冲突与恢复保护保持。

| 事实 | 用户文案/显示规则 |
|---|---|
| 配置已启用 | 已启用；不能写运行中或成功 |
| 配置已暂停 | 已暂停；配置仍保存 |
| 读取失败 | 后台状态未确认；缓存标为上次读取，不显示当前成功 |
| Agent 不可用 | 检测暂不可用；不能因宿主可连接就说正在监控 |
| HDR Enabled=true / Active=false | 已开启，但尚未生效 |
| 显示状态未知 | 状态未确认；不能当作已关闭 |
| 状态请求返回 | 展示绝对读取时间；不声称持续实时同步 |
| 回复丢失 | 结果未确认，保留输入，刷新核对；不宣称必定失败且自动重发 |

错误优先解释用户能做什么。内部异常/协议诊断留给技术记录，不能把长异常堆栈作为主要文案。已有后台原因尽量保留事实，后续协议结构化原因按实际需求增加，不让 UI 根据全局状态猜测某条规则执行成功。

## 视觉与可访问性

侧栏与品牌标题区统一深墨色，薄荷绿选中标记与图标明确当前位置，设置锚定侧栏底部；浅色为蓝灰工作区、白色内容卡、深色文字，深色为墨蓝工作区、稍浅卡片、浅色文字；两者保留绿色主动作，声明类别图标区分蓝/绿功能。页首采用图标、标题和单行副标题，不添加总览数字卡。一页只有一个主要任务。标题 28、卡标题 18–20、正文 14、辅助 12；统一 8/12/16/24 间距，避免大数字、编号导航、过多彩色徽章和装饰性空卡。

任务行提供轻量悬停反馈；工具标题、图标与开关统一排版，窄窗开关下移并保留可访问名称。应用 EXE、任务栏和自定义标题区域使用同一几何 A 图标；标题栏的品牌区延续侧栏颜色，其余融入当前主题背景，不再额外显示系统标题行。拖动区和原生最小化/最大化/关闭及缩放保持可用，按钮前景及悬停颜色随主题更新；弹窗使用工作台当前主题。系统模式使用 WinUI ActualThemeChanged 通知更新配色，无轮询；按钮在窄窗口内可收缩和换行。

列表整行占内容宽度，编辑表单单列且限宽；搜索和状态筛选压缩为单行，窄窗的任务工具栏分行显示；小窗口缩窄侧栏和留白、纵向滚动，不并排挤压列表与表单。说明优先使用有可访问名称的信息按钮（悬停提示、点击/键盘打开详情），行为与修改说明折叠展示；当前错误和恢复保护不隐藏。原生按钮/输入/对话框支持键盘和可访问名称。不得仅靠颜色区分状态。实际窗口检查默认尺寸与窄窗，不能用 HTML 效果图代替 WinUI 验收。更广泛 DPI/高对比度矩阵属于发布检查。

## 实现职责与扩展

- WorkbenchWindow：导航、编辑会话、未保存保护、请求期间互斥与确认流程。
- 页面重绘先离开输入/可访问性回调，构造脱离可视树的内容和页脚，完成后一次替换 ContentControl.Content；不直接 Clear 当前页面子集合。此方式修复原生编辑回调返回期间的 UIElementCollection.Clear 崩溃，侧栏和外壳保持稳定。
- WorkbenchWindow.Keyboard：HotkeyList 的应用内组合键编辑、顺序、去重/重复和批量输入；只保存声明参数，不监听或发送系统按键。
- WorkbenchWindow.Theme / UiThemePreference：界面配色与外观偏好；不读写规则或请求后台动作。
- WorkbenchWindow.Activity：日期分组的活动列表、分页、刷新与七天清理；通过受权 IPC 读取，不访问数据库，不生成假历史。
- WorkbenchWindow.Catalog / Groups / Toolbox：统一类型/工具入口卡片；进程组管理与共享批量输入、Steam 开关和名单/排除设置弹窗；顺序展示弹窗，复用受权读写。自动同步由 Host 的 SteamToolManager 执行，不依赖 UI。
- WorkbenchWindow.Tray：TraySelection 的应用内当前托盘搜索/刷新/勾选；通过 Host 读取真实会话名单，草稿独立、取消不提交，按窗口高度限制列表，不订阅后台周期刷新。
- WorkbenchWindow.TrayTool：工具箱托盘管理卡片、模式和名单草稿、启停/立即隐藏/结果刷新；只请求Host，后台持续监听不依赖窗口。
- WorkbenchWindow.Views：目录选择和字段渲染器；支持文本、多行文本、布尔、枚举、资源、文件/目录选择与范围数字输入；字段 Group 生成“更多选项”折叠区域。类型切换只更新参数与依赖区域，不销毁正在操作的下拉框；没有程序能力 ID 的专用表单分支。
- TaskEditorState：版本化编辑配置；切换检测清除不兼容动作，切换能力清除旧参数，取消/刷新保护用户输入。
- WorkbenchClient：现有受权 IPC 请求、响应校验和有限超时；不决定规则、不调用 Provider 或 SQLite。
- WorkbenchPresentation：通用保存错误文案；具体动作的结果解释属于后台适配器。

规则能力扩展通过 [任务接入 contract](../development/task-authoring-contracts.md) 完成，不复制新场景专用规则编辑页；工具箱可为明确场景提供直接交互，底层仍遵守受权执行边界。编辑器支持组合持续状态：全部/任一组和取反，可嵌套4层/16条件，逐叶复用声明字段、程序/名单/选择参数弹窗，支持上移下移、移入其他组及删除。后台目录声明支持组合后才显示入口；只选明确持续状态及每叶都兼容的动作，不提供事件取反或无效反馈组合。切回单检测不会自动删多个条件或取反，旧单检测/时段/导入暂停草稿和未保存保护保留；取反不把未确认当满足。新树按schema3及首叶兼容展示配置保存，Host仍须严格校验。明确“条件期间…结束恢复”的.restore动作由普通动作声明选择和行为说明接通，不新增全局policy表单；完整多步骤流程仍未接入。

打开、切页、手动刷新和规则操作才请求快照，无刷新 timer。未来若需要及时结果，扩展有界事件订阅，仅在窗口需要时订阅、关闭即释放，禁止用秒级轮询掩盖数据流缺失。

## 使用观察页

工作台提供显式、限时的使用观察入口；正在记录的范围、暂停/继续/结束、到期时间和关闭窗口即结束的行为持续可见。记录本地分页，可删除，结束后可补充观察目的。建议卡先解释证据和限制，确认后进入未保存且暂停的规则草稿；不直接启用。摘要/能力目录/扩展任务在可编辑预览中由用户复制，AI 建议粘贴后交 Host 严格校验。观察后台连接结束会推送状态刷新，无周期轮询。

## 常用场景草稿

自动化列表的“从常用场景开始…”基线预览 .4为56个默认暂停模板；之后按后台实际目录构建，不能将本轮未发布功能计入旧包。配方解释影响与退出语义，只根据后台实际目录和兼容组合提供；选择后复用通用编辑器，目标由用户补齐，草稿未保存且默认暂停。取消不更改任务，离开编辑器遵守未保存保护。模板不注册独立执行路径。

窗口检测另提供“程序窗口全部消失”；多选是全部选定程序都无可见主窗口，最小化不算消失，未知不猜测。窗口收尾模板解释后台仍可能运行、正常关闭可能需要保存确认。

“每隔一段时间”使用通用整数分钟字段，1–1440、默认30，明确是检测就绪后的相对周期。重连重新计时、不补发积压、不唤醒电脑；首次需完整等待。定期提醒模板要求用户填写http/https网址并提示重复标签页风险；不提供隐藏的URL或后台自动启用。

系统环境变化检测包含显示分辨率/色深变化，显示布局模板明确不识别特定屏幕组合。主动观察范围说明显示模式事件；相关布局候选先说明来源未知、机会次数和单窗口/当前显示器限制，再进入暂停草稿。

系统环境检测与观察范围仍包含任意USB接入/移除，相关建议不能筛选具体设备、复合设备可能多次通知，不随精确检测增加身份记录。独立“指定USB设备已接入/全部移除”通过通用名单弹窗手工填写设备管理器完整实例路径，最多16项；说明不是VID/PID或HID/存储子功能/接口路径，不推断父设备。同型设备也按完整实例区分，身份变化需更新配置；不提供尚未接通的发现面板，实例仅留本地，导出/AI导入只给待填占位。

默认音频观察范围独立且初始不选；说明默认播放设备与默认通信麦克风、不含设备标识。开启观察弹窗内容按可用高度滚动，范围增多时仍能访问期限、排除名单和目的。音频检测编辑提示区分Windows默认角色与应用自身音频路由，无法订阅时显示Unknown原因及恢复方式。

本地钟点检测用小时/分钟及多个星期勾选；单次日期用年月日和时刻，字段均来自能力声明。日历模板要求填实际目标，单次会议模板还要求填写日期。已到期/错过/过期显示明确原因，不冒充动作成功。

摘要预览与建议导入显示实时UTF-8字节大小，上限64 KiB。超限禁用复制/校验；导入校验或剪贴板失败留在弹窗并保留原文，允许直接修正。导入仍由Host校验，不因界面预检查省略后端验证；成功后另行确认，再进入暂停草稿。

默认播放音量动作提供设音量、静音、取消静音，明确一次性、不恢复和取消静音可能发声。锁屏静音模板默认暂停，用户审阅后启用；没有默认解锁取消静音，避免意外发声。音量字段说明仅设音量操作使用，设置音量不会解除静音。

默认通信麦克风动作只提供静音/取消静音，快捷键模板默认静音且需填写快捷键。提示输入音量不变、应用自选设备不受保证、并非硬件隐私开关；取消静音可能恢复收音，必须审阅。

已处理建议旁提供恢复入口及数量：恢复当前记录中模式对应的跨记录反馈，不改已有规则或删除记录。草稿未保存也能重新审阅。摘要把这些模式放入 `handledPatterns` 并提醒AI不要重复建议；本地路径/反馈哈希仍不导出。

文件到达检测通过通用目录路径字段与类别选项配置；PDF工具模板要求填写目录和程序。明确一秒合并、新建/重命名均可触发、文件出现不等于下载完成，动作不接收文件名；目录由用户手工配置，AI导入不能注入路径。

导入确认页会列出必须手工补充的目录、网址或显示器等字段；进入现有暂停草稿后由用户填写/选择。未补齐时正常保存校验拒绝，不把待补全草稿显示为已配置成功，也不把AI提供的路径预填进可执行字段。

观察开始与扩展需求弹窗在原位校验及等待后台；失败保留范围、期限、排除项和需求文字。提交时禁用输入和重复关闭，完成后恢复；打开观察过程中关闭主窗口也立即释放待确认的管道，防止留下失去UI的观察。扩展任务仅后台成功返回后进入预览，复制仍需显式点击。

打开目标的文本字段通过 `BrowseLocalPath` 声明提供“选择文件/文件夹”，网页仍可直接输入；选择后仍按打开类型正常校验，取消/选择器失败保留旧值，等待时禁用同组选择按钮。提醒正文使用通用多行文本字段，可换行。模板说明统一提示填齐所需内容，避免误导为只有程序参数。

选中任意观察记录后都有独立“补充需求并生成开发任务”入口，不依赖已有建议或外部AI返回。建议卡片进入该流程时带入问题标题并显示观察线索，仍要求用户填写操作前后希望改变的行为；线索不证明缺能力，任务包不默认附原始记录或对象映射。补充观察目的同样等待后台确认、失败原位保留输入。

任务列表支持本地关键词匹配任务名称、检测/动作名称，以及全部/已启用/自动暂停/手动暂停筛选，显示匹配数量；筛选在本次窗口的编辑返回/刷新中保留，不向后台发送查询或修改规则。无匹配项给出修改筛选提示。常用场景弹窗支持名称/描述关键词，保留仍匹配的选择，没有结果时禁用打开草稿按钮。

“运行方式”的“自动暂停”独立配置主屏HDR开启/关闭时暂停，以及允许运行的本地周时段；可同时启用。条件不满足时停止整个任务内部检测，列表显示自动暂停及原因，满足后重新读取检测。手动暂停保持用户选择。列表打开时使用后台状态推送，无定时刷新；断开显示状态未确认并提示刷新。编辑时停订阅，配置草稿与取消沿原保护，旧后台不允许保存新条件。

一次性动作目录声明支持后，“运行方式”可开启“只在选定时段执行”，选择本地起止时间及多个星期；跨午夜属于起点星期。保存/重开保留，缺日期或相同起止拒绝。切到不支持的动作保留原限制并明确要求关闭或换回，不静默丢弃。规则卡显示时段及上次读取的门禁信息；刷新仍按需，页面不会每秒更新时间。时段外触发/延迟/排队跳过，进入时段不补发，已开始动作不撤回。

Wi-Fi配置名和USB设备实例名单使用声明式`EditAsList`：主表单紧凑摘要，应用内弹窗批量编辑，16项/每项255字符、保留名称空格与大小写，取消不改，错误原位保留。UI按整行Ordinal去重，USB最终能力校验按大小写不敏感整项规范，Wi-Fi保留其名称匹配语义；新增检测不需要能力ID表单分支。无接口可确认USB不在，查询未知不能显示“已移除”；首次/恢复不补一次性动作，保持唤醒则按当前条件持有/释放。

“把窗口移到显示器”复用完整程序名单、标题筛选和窗口等待；目标Choice只提供主屏/下一个/上一个，解释按执行时桌面坐标排序循环、中央80%、单屏切换跳过。两种新模板分别为快捷键移下一屏、显示变化后移主屏；不提供设备身份选择、旧坐标恢复或持续固定开关。未确认结果保留后台原因，可能已还原/移动不冒充无副作用。

“锁定当前Windows会话”只提供延迟与一次性动作时段选项，明确是请求而非锁定完成。离开所选Wi-Fi锁屏模板要求手工补齐配置名、审阅后显式启用；已锁定/非活动/未知拒绝、正常登录解锁，不展示自动解锁或撤销锁定按钮。暂停仅能取消尚未发出的请求；关闭UI不停止已启用规则。

六种亮度动作均有“渐变设置”折叠项：渐变亮度默认关，渐变时长1–15整数秒、默认3；新增渐变平滑度1–60整数次/秒、缺省10、推荐18，表示写入请求上限而非面板帧率。时长越大变化越慢，受设备响应与亮度粒度影响；硬件中段按所选频率、末笔至少间隔100ms并严格读回。正常条件结束的恢复也渐变；硬件采用最多1秒连续写入段再核对以减少阶梯，段内手动调整可能被覆盖；取消、失败及段末未确认让出，稳定持有不定时写入。旧规则省略参数保持直接设置。普通亮度优先活动内屏，明确没有内置接口才选择主屏硬件；0–100及延迟沿通用字段，不增加设备身份选择器。电池调暗与低于25%调至30%模板默认暂停，明确一次调整、接电/条件结束不恢复。

默认设备静音检测通过通用选项选择通信麦克风/常规播放、已静音/已取消静音；不显示或保存设备ID、不声称录音状态。首次或默认选择切换不补一次性动作，Unknown释放持续动作；开麦期间保持唤醒模板说明首次已取消静音可生效，不代表会议实际收音。

供电条件通过通用选项选择接电/电池供电/电池供电且低于阈值，1–99整数阈值仅最后一种使用，严格低于。接电保持系统唤醒模板默认暂停，允许屏幕关闭，拔电/Unknown/暂停释放；该条件不是一次接电事件，也不修改全局方案。

“程序窗口状态”使用通用完整exe多选字段和最小化/最大化/普通三选一，无标题字段；任意匹配可见主窗口满足即成立。普通不含隐藏/没有窗口，最小化仍算可见，最大化不等于全屏演示，也不证明是用户操作。首次/未知恢复不补一次性动作；持续保持唤醒可使用已知初始条件，Unknown/条件结束/暂停释放。最大化保持系统及屏幕唤醒模板默认暂停，须手选程序后审阅启用；关闭UI不停止已启用检测。不提供整理状态/移屏组合，避免规则改变自身条件；编辑器继续由字段和组合声明生成。

“显示器数量条件”通过通用至少/恰好与1–16整数配置，提示统计Windows逻辑桌面，不保证物理屏幕数或识别具体屏幕。多屏保持系统唤醒模板已填至少2屏但默认暂停，允许屏幕关闭；返回单屏移主屏模板需手选程序，首次/睡眠恢复不补移动、不恢复旧坐标。查询未知不显示单屏，持续请求在Unknown/结束/暂停释放。

“Windows报告的Internet状态”通过通用可用/不可用选项配置，提示仅依据Windows报告、VPN/NCSI策略可能影响且不保证网站/目标服务可达；没有网络名或设备身份输入。Internet可用后启动工具模板需用户选择完整exe，默认暂停、首次已有Internet不补启动。无主动ping/HTTP探测，未知不显示离线；已知持续条件可保持唤醒，结束或未知后释放。

“当前会话屏幕电源状态”由通用亮着/已变暗/已关闭三选一配置，无显示器身份或内容输入。状态未收到Windows有效报告前显示未知；不把锁屏、屏保或黑画面当屏幕已关，不代表远程客户端物理屏幕。提供一次音频调整/麦克风、当前媒体控制、提醒和关闭工具，不提供保持唤醒或显示设置组合。“当前会话屏幕关闭后静音”和“当前会话屏幕关闭后暂停媒体”均为未保存暂停草稿；首次、恢复或重新启用不补动作，屏幕亮起也不自动恢复。关闭UI不停止已启用检测；现代待机可能暂停后台或推迟动作。

“控制Windows当前媒体会话”通过通用操作选项选择暂停、播放、上一项或下一项，执行时由Windows选中一个会话，无程序路径或曲目输入。锁屏后暂停媒体模板默认暂停，不自动在解锁后播放；成功只代表请求接受，目标切换或操作不支持会解释。整理窗口状态的既有布局选项追加当前显示器四角四分之一，仍是一次性整理、读回确认，不恢复旧位置。
